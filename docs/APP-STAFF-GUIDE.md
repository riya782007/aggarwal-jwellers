# Aggarwal Jewellers app — staff guide / स्टाफ गाइड

The app is the same shop system you already use, now on the phone. Same login, same bills, same stock.
ऐप वही दुकान का सिस्टम है जो आप पहले से इस्तेमाल करते हैं — अब फ़ोन पर। वही लॉगिन, वही बिल, वही स्टॉक।

## Install (once) / इंस्टॉल (एक बार)

1. Open the download link on the phone and tap **aggarwal-jewellers.apk**.
   फ़ोन पर डाउनलोड लिंक खोलें और **aggarwal-jewellers.apk** पर टैप करें।
2. If asked, allow **"Install unknown apps"**.
   पूछे तो **"Install unknown apps"** की अनुमति दें।
3. Open **Aggarwal Jewellers** and log in with your usual passcode.
   **Aggarwal Jewellers** खोलें और अपने पासकोड से लॉगिन करें।

## Connect the sticker printer (once) / स्टिकर प्रिंटर जोड़ें (एक बार)

1. Switch the printer on and keep it near the phone. Turn on Bluetooth.
   प्रिंटर चालू करें, फ़ोन के पास रखें। ब्लूटूथ ऑन करें।
2. Tap **Print labels** on any item. The printer screen opens by itself.
   किसी भी आइटम पर **Print labels** दबाएँ — प्रिंटर स्क्रीन अपने आप खुलेगी।
3. Tap your printer's name, then **Allow** Bluetooth. A test sticker prints.
   प्रिंटर का नाम दबाएँ, फिर ब्लूटूथ **Allow** करें। एक टेस्ट स्टिकर निकलेगा।
4. Go back and tap **Print labels** again. From now on it prints straight away.
   वापस जाकर फिर **Print labels** दबाएँ। अब हर बार सीधे प्रिंट होगा।

## Every day / रोज़ का काम

- **Billing, stock and labels** work exactly as on the computer.
  **बिलिंग, स्टॉक, लेबल** — सब कंप्यूटर जैसा ही।
- **Scan a QR:** use the camera button on the Billing screen.
  **QR स्कैन:** बिलिंग स्क्रीन पर कैमरा बटन।
- **A4 GST bill:** tap Print and choose the shop printer or "Save as PDF".
  **A4 GST बिल:** Print दबाएँ, दुकान का प्रिंटर या "Save as PDF" चुनें।

## If something goes wrong / कोई दिक्कत हो तो

| Problem / दिक्कत | Do this / यह करें |
| --- | --- |
| "Printer not reachable" | Switch the printer off and on, bring the phone closer, tap Print again. / प्रिंटर बंद-चालू करें, फ़ोन पास लाएँ, फिर Print दबाएँ। |
| Stickers print shifted / स्टिकर खिसके हुए | Labels → Bluetooth printer setup → **Calibrate roll**. / **Calibrate roll** दबाएँ। |
| "No internet" screen | Check Wi-Fi or data, tap **Retry**. Bills are safe on the server. / वाई-फ़ाई या डेटा देखें, **Retry** दबाएँ। बिल सुरक्षित हैं। |
| Phone or app problem / फ़ोन या ऐप में दिक्कत | Use the computer or Chrome as before. Everything is already there. / पहले की तरह कंप्यूटर या Chrome पर काम करें — सब वहीं मिलेगा। |
